Word：保留可編輯文字、字級、顏色、段落、表格和圖片；PDF：此模式以頁面圖片保留原外觀（無法逐字編輯）。PPT 的複雜圖形／動畫仍無法完整還原。

05
READY TO PUBLISH
複製與下載 HTML
確定排版無誤後再匯出。貼到一般網站編輯器時，建議先使用「複製 HTML」。
樣式整理：尚未產生 HTML只輸出行內 style：重複屬性自動清理，適合繼承的文字樣式集中到外層；保留需要獨立設定的間距、框線與色彩。
圖片上架提醒
下載 ZIP 內的 images/ 是相對路徑。若只複製 HTML 至 CMS，圖片必須先上傳網站圖庫並改成實際網址，才能正常顯示。
其他工具與偏好設定
本機處理為主 · API 功能須自行設定 · 請勿在未授權的服務上傳機密文件




外部服務設定
設定會儲存在這台裝置的瀏覽器 localStorage。不要在這裡輸入 AI 平台的秘密 API Key。
CMS API 預期以 multipart/form-data 接收圖片，並回傳 JSON：{ "url": "https://..." }。不同 CMS 必須由工程師製作對應的安全上傳端點。



進階富文字編輯器
編輯表格、文字與圖片後，按「套用到文章」同步至原始碼、預覽與匯出。


圖片請使用實際圖庫網址；勿貼入 Base64 圖片。




整理後的 HTML 程式碼
不使用 class 或 style 標籤，僅整理必要的行內 CSS。
最終輸出只有 HTML 標籤與行內 style；表格框線、各段落間距等不可繼承的樣式仍須保留。
