# 文轉網 PRO V14｜文章排版、圖片與 CTA 格式

本版本以 V13 的 Word／Excel／PPT／PDF 轉換工具為基礎，增加第 02 步的「文章排版、圖片展示、CTA」三種樣式工具。**產出給客戶 CMS 的 HTML 僅使用行內 `style`；不需要貼 `<style>`、CSS class 或 JavaScript。**

## 操作流程

1. **01 匯入**：上傳 DOCX、XLSX、PPTX、PDF，或直接貼 Word／純文字。先核對原文是否正確。
2. **02 美化**：先選整篇文章模板、表格與列表樣式，再往下選文章排版、圖片樣式和 CTA。
3. **文章排版**：六種選項：清爽閱讀、章節分隔、色條標題、淡底標題、雜誌置中、編輯專欄。可調整主標題字級與章節間距。
4. **圖片樣式**：六種選項：自適滿寬、置中展示、半幅配圖、極細相框、留白相片框、底線展示。可調整圖片比例、上下距離和框線顏色。圖片輸出始終維持 `height:auto`、`max-width:100%`，避免被壓扁。
5. **CTA 樣式**：六種選項：品牌實心、線框簡約、深色商務、柔和提示、整幅色帶、專欄導流。輸入標題、說明、按鈕文字、實際 URL，選擇顏色、對齊、間距、插入位置與外部連結開啟方式。可新增、更新或移除**最後一個**由工具產生的 CTA。
6. 按下 **「套用排版／圖片／CTA 樣式」**，只更新現有文章中的標題、圖片與 CTA 樣式；不會重寫內文。按 **「套用目前排版設定」** 則會重新套用整篇文章模板、表格、列表及新增樣式，可能覆寫部分先前的個別樣式，應檢查預覽。
7. **03 預覽與編輯 → 04 檢查 → 05 複製／下載 HTML**。先用目標 CMS 編輯器貼上、儲存再檢查一次。

## 新增檔案

- `assets/content-design-v14.css`：工具 UI 卡片及表單的樣式，**不會進入匯出的文章 HTML**。
- `assets/content-design-v14.js`：文章排版、圖片、CTA 樣式設定／套用；CTA 文字透過 `textContent` 產生，URL 經過限定檢查。

同時更新 `index.html`、`assets/app.js`，並保留 V13 原有的 `assets/structure-v13.js`、`assets/structure-v13.css` 等檔案。請整包更新，不要只替換 `index.html`。

## CTA 的 HTML 做法

CTA 使用一般 `<section>`、`<h3>`、`<p>`、`<a href>`，全部以個別元素的 `style` 屬性描述格式；`<section title="文轉網CTA">` 是工具內用於再次找到 CTA 的安全識別標記。若 CMS 在儲存時移除 `title` 屬性，**前台 CTA 仍能顯示，但重新匯回工具時可能無法識別舊 CTA**。請注意後台是否保留 `a[href]`、`style` 與段落標籤。

CTA **不會自動產生虛構連結**，按鈕連結是必填。支援 `https://...`、`http://...`、`/contact`、`#section` 以及 `mailto:`／`tel:` 等格式；不接受 `javascript:` 等危險 URL。外部網址可選另開分頁，並加上 `rel="noopener noreferrer"`。

## 圖片路徑和 CMS 限制

圖片只更改展示樣式，不會自動上傳圖庫、不會把相對路徑變成公開網址。從 DOCX 提取的 `images/文件名稱-01.png` 必須連同圖片資料夾上傳，或在第 03 步「圖片管理」替換成 CMS 圖庫的真實網址；否則只複製 HTML 到另一個網站，圖片可能無法顯示。

### 相容性注意

- 只使用行內 CSS；不依賴 `flex`、`grid` 或 JavaScript 來排版輸出文章。工具**自身介面**仍使用 CSS class，這與輸出 HTML 不同。
- 章節樣式以 `h2/h3` 為主；若貼入的內容全是 `p`，建議先在視覺編輯器把標題改為 H2/H3。
- 圖片樣式會套用到文章所有圖片；單張微調請到第 03 步編輯。
- CTA 是純連結導流，不會直接提交表單、送出資料或追蹤轉換；若要用 LINE、詢價頁、預約頁，請填入實際連結。
- CMS 可能會在貼上或儲存後清理 `style` 或特殊 HTML，請在真實客戶後台測試。
- GitHub Pages／Cloudflare Workers 靜態版可使用前端工具，但 `api/ai.php` 需另外部署在支援 PHP 的環境。

## 驗證

- JavaScript 已通過 `node --check`。
- 已在本機 Chromium 的**離線 HTML 注入測試**中驗證：18 種卡片建立、選擇操作、CTA 插入／更新／移除、圖片展示設定、輸出不含 `<style>` 或 `class`、手機寬度無水平溢出。
- 離線測試中的安全清理使用測試替身，**不等同正式 CDN DOMPurify 及各家 CMS 後台端到端驗收**。

## 部署

將本 ZIP 解壓縮後所有內容放到 GitHub 專案根目錄，再透過既有 Cloudflare 部署。請確認 `index.html`、`assets/`、`api/` 都在預期位置。上傳後使用強制重新整理，避免瀏覽器暫存舊版檔案。
