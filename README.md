# 文轉網 PRO V12｜五步驟直覺操作介面

在 V11 行內樣式轉換核心上重整操作介面，不更動客戶 CMS HTML 的輸出格式。

## 操作順序

1. **匯入內容**：依需求選擇貼上 Word／純文字、單份檔案，或 30 份批量轉換。貼上可透過「產生美化 HTML」建立文章。
2. **美化排版**：10 個可視化模板、主色、字級、行距、段落間距，進階展開 CMS 相容設定。按「套用目前排版設定」更新既有內容。
3. **編輯預覽**：預覽桌機／手機、視覺編輯／Jodit 進階編輯、HTML 原始碼、圖片管理。
4. **檢查內容**：CMS 相容性檢查、SEO／AI 建議。
5. **複製匯出**：預設「精簡行內樣式」，複製 HTML、複製富文字、下載 HTML 或 HTML＋圖片 ZIP。

## 注意事項

- 核心輸出保持 V11 規則：行內 `style`，無 `<style>`、class 等外部 CSS 依賴。
- 首頁的 CSS 只是工具自己的 UI，不會被複製到客戶網站 HTML。
- 圖片如需貼到網站後台，請先上傳 CMS 圖庫，再填入公開的圖片路徑。
- Cloudflare Worker Pages 靜態部署不會執行 PHP AI 代理；需自行配置伺服器。
- 模板卡片僅選擇樣式。貼上並產生 HTML 才建立文章；既有文章請按「套用目前排版設定」。

## 部署

將壓縮檔內的檔案及資料夾複製到 GitHub 專案根目錄、提交即可觸發已配置的 Cloudflare 自動部署。新增：`assets/workflow-v12.css`、`assets/workflow-v12.js`。不要漏上傳。
