# 文轉網 PRO V8.0｜原文優先貼上轉 HTML

## V8 新增：貼上 Word／純文字，再美化 HTML

- 點左側「直接貼上文字」或頂部「貼上轉 HTML」。
- **從 Word 貼上**：在 Word 複製內容，再貼到富文字區；保留基本標題、粗體、段落、清單、表格與連結（過多的 Office 樣式會清除）。
- **純文字貼上**：直接貼原始文字，空白行分段、`##` 與 `###` 識別標題、`•`/`-`/`1.` 清單、Tab 資料轉表格。
- 設定「首段 H2」、「章節識別」、「保留換行」與「保留原清單符號」。預設優先保留文字，**不調用 AI、不改寫或補完內容**。
- 選擇左側模板、顏色、行距與間距後按「產生美化 HTML」，原本的預覽、Jodit 編輯器、CMS 檢查、圖片管理、HTML/ZIP 匯出都能使用。
- 產生後會顯示原文與 HTML 擷取文字的字數及比對結果。比對採不計空白和明確 Markdown 標題符號的方式；如果有差異，請打開來源 / 結果對照核對。
- 對 PDF 辨識錯字，**建議改用這個貼上模式**；無法保證 PDF/OCR 本身的辨識結果正確。

### 上線及注意事項

1. V8 採現有 V7 程式為基礎，增加 `assets/paste.css` 和 `assets/paste.js`。更新 GitHub 根目錄的 `index.html`、`README.md` 與 `assets/` 對應檔案。
2. 仍透過 CDN 載入 DOMPurify、Jodit、Mammoth、SheetJS、PDF.js 等依賴。瀏覽器若無法連線 CDN，轉換功能不能正常使用。
3. Word 貼上時圖片可能因剪貼簿權限或應用程式限制而無法完整保留；圖片較多時請用 DOCX 匯入，再用圖片管理上傳圖庫與替換 URL。
4. Cloudflare Workers/Pages 靜態部署不能直接執行 `api/ai.php`，AI 功能仍需獨立 PHP 主機或 Worker API。
5. 自動標題判別與 Word 表格結構需視來源檢查。原文核對只用於輔助，不是語義正確性的保證。
6. 單純貼 HTML 至不同 CMS 可能會被後台移除行內樣式或圖片路徑，請上線前用實際 CMS 測試。

# 文轉網 PRO V7｜批次轉換與暫停取消

## 新增功能
- 單筆：暫停、繼續、取消。
- 批次：一次選取最多 30 份文件，每份上限 25 MB，依序轉換，獨立狀態、取消、重試、成果預覽。
- 完成後一鍵下載所有成功成果的 ZIP，內含 `documents/文件名稱-編號/index.html` 和同資料夾 `images/`。
- 批次成果可以載入編輯器再繼續美化；載入後的改動不會自動修改已排入批次輸出的原始成果。

## 暫停／取消語意
第三方 Office 解碼、PDF 渲染、OCR 辨識的一部分無法從瀏覽器中強制中斷。暫停／取消會在下一個合作式檢查點生效（如 PDF 每頁、PPT 每頁及一份文件完成前），不是立即終止底層計算。取消不會輸出未完成檔案。請勿在處理期間重新整理網頁，否則尚未下載的資料會遺失。

## 如何更新
把本 ZIP 的 `index.html`、`assets/`、`api/`、`README.md` 覆蓋你原本的 GitHub 儲存庫，Cloudflare 連結 GitHub 時會重新部署。此版為靜態前端工具，`api/ai.php` 仍需 PHP 主機。所有檔案由瀏覽器在本機處理，依賴 CDN 套件。

## 重要限制
- 「批量上傳」目前支援一次選多個文件，以及產出多份 HTML 與圖片 ZIP；不是自動將文章發布至 CMS。
- 若需要批量發布文章或圖片至客戶 CMS，必須由 CMS 提供具認證、權限控管與 CORS 規則的安全 API。
- CMS 貼上相對圖片路徑前，請先將圖片上傳至客戶網站，並替換成實際網址。
- 單筆和批次共用一個轉換核心，避免同時進行；批次期間請勿編輯文章或改動模板設定。

# 文轉網 PRO — 文件轉 CMS HTML

**版本：2、3、4 合併版／靜態網站 + 可選 PHP AI 代理。**

## 快速使用

1. 將整個資料夾上傳至 HTTPS 網站空間，例如 `https://example.com/html-converter/`。
2. 透過 `index.html` 開啟；Word / Excel / PPT / PDF 的轉檔依賴第三方 CDN，首次載入需要網路。
3. 上傳檔案（25 MB 以下），選擇「可編輯內容」或 PDF「頁面視覺保留模式」。
4. 到「視覺編輯」「HTML 原始碼」調整內容，執行「CMS 檢查」。
5. 點「複製 HTML」或「下載 HTML」，貼入 CMS 的 HTML 原始碼編輯模式。

## 功能及限制

| 功能 | 說明 |
|---|---|
| Word DOCX | Mammoth 解析文章、表格、圖片；無法完整還原 Word 每一個視覺細節 |
| Excel XLSX/XLS | SheetJS 產生 HTML 表格；複雜圖表、公式視覺樣式不保證還原 |
| PPTX | JSZip 擷取逐頁文字，按投影片關聯擷取支援的圖片；不還原任意圖形座標及動畫 |
| PDF | PDF.js 擷取文字；掃描/無文字頁可啟用 Tesseract 繁體中文+英文 OCR（首次下載語言模型） |
| PDF 視覺保留 | 將 PDF 每頁轉為 JPEG 並放入 HTML；保留外觀但不能逐字編輯，圖片可能很大 |
| 圖片管理 | 圖片預覽、單張/整包下載、替換圖片路徑，選配 CMS 圖庫 API |
| CMS 相容檢查 | HTML 安全清理、圖片/連結/表格/標題等靜態檢查。**不能代替在目標 CMS 實際儲存/預覽驗收** |
| SEO | 標題、摘要草稿、基本提示、SEO JSON 匯出；實際 meta 要在 CMS 頁面設定 |
| AI | 部署 `api/ai.php` 並在主機設 `OPENAI_API_KEY` 後可使用；預設不會送文件到外部 AI |

## 資料隱私

- 一般文件處理在瀏覽器內完成，不會主動將文件上傳到文轉網伺服器。
- CDN 加載 JS/OCR 模型，會對 CDN 發出請求。使用「CMS 圖庫上傳」會把圖片傳到指定 API；使用 AI 才會將文章內容傳到自己配置的代理，再轉送 AI 提供商。
- 瀏覽器 `localStorage` 只儲存偏好、API 端點，不儲存文件內容及金鑰。
- HTML 在前端經 DOMPurify 淨化；**服務端 CMS 仍需再次清理 HTML**，並限制可接受的標籤及 CSS。

## 可選：啟用 AI

1. 主機需有 PHP 8.1+、`curl` 和 `mbstring` 擴充套件。
2. 將 `api/ai.php` 上傳至相同網站來源。
3. **在伺服器環境變數** 設定 `OPENAI_API_KEY`。可選 `OPENAI_MODEL`；不要將金鑰寫在 HTML、JS 或任何前端可讀檔案。
4. 到「圖片上傳與 AI 設定」填寫 `api/ai.php`（預設值）。
5. 正式公開上線前，必須加入登入權限、CSRF 防護、用戶級配額、監控及費用上限。範例代理程式只有基本的同來源檢查與 session 限流，**不是公開營運的完整安全方案**。

> 如果沒有設置 API 金鑰，SEO 規則建議仍可使用，但 AI 重寫按鈕會明確報錯。

## CMS 圖片 API 契約

- URL 可透過設定視窗輸入。
- `POST` `multipart/form-data`，欄位名稱預設 `file`。
- JSON 回傳：`{"url":"https://example.com/uploads/123.jpg"}`。
- 如果 CMS API 與轉換工具不在同一網域，CMS API 必須有明確 CORS 設定及驗證機制。
- 範例未提供真實 CMS API，因為各網站認證及上傳流程不同。沒有填 API 時，圖片可下載並由客戶手動上傳到網站圖庫，再替換網址。

## 部署與驗收

- 請用 HTTPS 網站打開，避免瀏覽器對剪貼簿功能設限。
- 用目標 CMS 實際確認 `h2/h3/p/ul/table/img`、`style` 屬性和圖片外連 URL 在「儲存後」不被清掉。
- PDF 頁數多或 PPT 圖片大時可能耗費大量記憶體；目前 25 MB 是檔案大小限制，不代表一定能順利處理所有大型文件。
- 本專案是可自行部署的完整原始碼，不含網站主機、API 密鑰、真實 CMS 權限或已部署的線上服務。

## PRO 5.0 更新：排版與圖片管理

- 預設圖片輸出為 `images/<文件名稱>-01.png` 等相對路徑，不把 Base64 長字串保留在最終 HTML。
- 按 **下載 HTML＋圖片 ZIP**，取得 `index.html` 和 `images/` 目錄。兩者請維持相同目錄關係部署。
- 若是將 HTML 片段直接貼到客戶 CMS 編輯器，請先透過 CMS 圖庫上傳圖片、將 `images/...` 路徑替換為後台提供的實際網址。純粹貼上相對路徑無法保證圖片會顯示。可利用「圖片素材管理 → 上傳 CMS」功能，但必須先設定經過授權的 CMS 圖片 API，且 API 須支援來源檢查、身份驗證與上傳限制。
- 視覺編輯區新增點選段落、標題或圖片後的屬性編輯：字型、粗細、字色、背景色、字級、對齊、間距、圖片寬度與 alt；也可插入本機圖片。
- 模板數增至 10 款，新增行距、段落間距、內容寬度設定。
- 未實作真實伺服器上傳 / OCR 準確率保證 / PPT 逐像素還原；舊版 AI API 仍需支援 PHP 的伺服器與金鑰。

### 重要操作差異

- 「複製 HTML」輸出的圖片路徑是相對路徑，適合搭配完整 ZIP 部署，不會自動將圖片上傳到客戶站台。
- 若使用 Cloudflare Workers 靜態部署，前端 HTML/JS 可正常服務，但 `api/ai.php` 不會執行。AI 功能需另部署 PHP API 或改寫為 Workers API。
- 此版本通過靜態語法檢查。執行環境的瀏覽器存取受限，尚未完成跨瀏覽器端到端測試，正式上線前需用測試 DOCX、XLSX、PPTX、PDF 驗證。


## V6：已接入進階富文字編輯器

- 套件：Jodit 4.17.4（MIT），透過 jsDelivr 固定版本載入。
- 操作：進入網站，按工具列「✎ 進階編輯器」，使用圖片、表格、字型、字級、顏色、對齊、清單、連結及 HTML 原始碼功能。按「套用到文章」才會同步到既有轉檔頁面，按取消則不覆蓋。
- 如網路無法連接 CDN，既有轉檔、基本編輯、匯出仍可使用；進階編輯器需網路。
- 影像注意：不將 Base64 圖片視為可直接貼入 CMS 的正式路徑。請上傳到網站圖庫並改成完整 URL，或使用既有 HTML＋圖片 ZIP 工作流程。
- Cloudflare Workers 的網站可直接部署靜態版；PHP AI API 仍需額外後端。
- 安全：用既有原始碼頁籤的 sanitizer 清理進階編輯器內容；CMS 實際允許的標籤仍需實測。
